# 🪑 Workspace Builder (3D Configurator)

Design and customize your ideal workspace by selecting desks, chairs, monitors, and accessories — with real-time feedback and interactive 3D models.

---

## ✨ Features

- 🧩 Modular workspace builder (desk, chair, monitor, accessories)
- 🎯 Real-time selection updates
- 🪄 Interactive 3D model previews (`.glb`)
- 🧾 Dynamic summary with total pricing
- 🎨 Clean UI with smooth animations (Framer Motion)
- 🛒 Smart selection logic (single + multi-select)

---

## 🛠 Tech Stack

- **Next.js (App Router), React, TypeScript**
- **Tailwind CSS** for styling
- **Framer Motion** for animations
- **model-viewer** for 3D rendering
- **Lucide React** for icons
